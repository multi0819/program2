# 시설 운전보고 Android

Android 11 이상. 로컬 웹 화면과 Android WebView를 사용합니다. 보고서 입력·장소 목록은 앱 안에 저장되며 인터넷 없이 작성할 수 있습니다. 날씨 조회는 인터넷과 위치 권한이 필요합니다.

## 빌드

JDK 17, Android SDK 35, Gradle 8.11.1 환경에서 `gradle :app:assembleDebug`를 실행합니다. 배포 업데이트에는 같은 서명 키를 사용해야 합니다. 서명 키는 저장소에 포함하지 않습니다.

## 기능

6개 보고 항목, 점검 장소 추가, 특이사항, 메시지 복사와 카카오톡 열기, 사진 선택·갤러리 저장.

웹앱과 APK는 저장 공간이 분리되어 있습니다. 기존 브라우저 입력 내용은 APK로 자동 이전되지 않습니다. 앱 데이터 삭제나 앱 제거 시 작성 내용도 삭제됩니다.

## 검증

보고서 6개 생성, 빈 특이사항 처리, 입력과 장소 목록 재실행 복원, 초기화, 중복 장소 차단을 DOM 테스트로 확인했습니다. APK 컴파일·서명·정렬을 검사했습니다. 실제 휴대폰에서 카톡 열기·사진 저장·위치 권한은 추가 확인이 필요합니다.
